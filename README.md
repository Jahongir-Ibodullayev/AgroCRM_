## 📖 Loyiha haqida

`AgroCRM_` — agro sohasidagi mijozlar, buyurtmalar, yetkazib berish va
moliyaviy hisobotlarni boshqaruvchi tizim.

## ✨ Asosiy funksiyalar (reja)

- 👥 **Mijozlar bazasi** — kontaktlar, segmentatsiya, tarix
- 🛒 **Buyurtmalar** — qabul, holat, yetkazib berish
- 📦 **Ombor** — mahsulot qoldig'i, harakatlar
- 💰 **Moliya** — to'lovlar, hisobotlar
- 📈 **Dashboard** — savdo dinamikasi, KPI
- 🔔 **Bildirishnomalar** — email / Telegram

## 🚀 Ishga tushirish

```bash
git clone https://github.com/Jahongir-Ibodullayev/AgroCRM_.git
cd AgroCRM_
python3 -m venv venv
./venv/bin/pip install -r requirements.txt
cp .env.example .env
```
